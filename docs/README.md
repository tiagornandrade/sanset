# 📚 Documentação do Projeto Sanset

Bem-vindo à documentação do projeto Sanset. Esta pasta contém toda a documentação técnica, guias de configuração e checklists do projeto.

## 🚀 Início Rápido

### Para fazer deploy

1. Leia o [DEPLOY_CHECKLIST.md](./deploy/DEPLOY_CHECKLIST.md)
2. Configure o billing (veja [BILLING_REQUIREMENT.md](./deploy/BILLING_REQUIREMENT.md))
3. Configure os secrets no GitHub
4. Faça push para `main`

### Para desenvolvimento

1. Veja o [TODO.md](./development/TODO.md) para itens pendentes
2. Configure o formulário seguindo [FORM_SETUP.md](./development/FORM_SETUP.md)
